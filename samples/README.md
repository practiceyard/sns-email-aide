# Samples

Copy-paste (or import) starting points for consuming the SNS Email Aide. See the
top-level [README](../README.md) for the invoke contract these build on.

| Sample | What it shows |
|--------|---------------|
| [`aide_client.py`](aide_client.py) | Importable Python (boto3) client wrapping register/status/history/delete. |
| [`github/`](github/) | Invoking the aide from a GitHub Actions runner via OIDC (setup notes + workflow). |
